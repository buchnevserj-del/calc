# Пошаговая инструкция: Подключение Supabase к калькулятору GlassLoft

**Supabase** — это современная облачная база данных (PostgreSQL), которая на 100% бесплатна для использования (**тариф Free навсегда**, без ввода банковской карты).

Синхронизация через Supabase позволит вам мгновенно видеть все расчёты и сметы на всех смартфонах и компьютерах компании.

---

## 🚀 4 простых шага для подключения (займёт 2–3 минуты):

### 📌 Шаг 1. Создание бесплатного проекта в Supabase
1. Перейдите на сайт **[supabase.com](https://supabase.com/)** и нажмите зелёную кнопку **«Start your project»** (или войдите через GitHub / Email).
2. Нажмите **«New Project»** (Новый проект).
3. Заполните поля:
   * **Name** (Название): `glassloft`
   * **Database Password** (Пароль базы): придумайте пароль (например, `GlassLoft2026!`).
   * **Region** (Регион): выберите любой европейский (например, `Frankfurt (eu-central-1)` или `London`).
   * **Pricing Plan**: убедитесь, что выбран **Free** ($0/month).
4. Нажмите **«Create new project»**. Подождите около 1–2 минут, пока проект развернётся.

---

### 📌 Шаг 2. Создание таблицы для смет (1 клик в SQL Editor)
1. В левой панели меню Supabase нажмите на значок **«SQL Editor»** (иконка терминала `>_`).
2. Нажмите кнопку **«New query»** (или знак `+`).
3. Скопируйте и вставьте следующий SQL-код:

```sql
-- 1. Создаём таблицу history для хранения смет
create table if not exists history (
  id text primary key,
  data jsonb not null,
  timestamp bigint,
  created_at timestamptz default now()
);

-- 2. Включаем безопасность строк
alter table history enable row level security;

-- 3. Разрешаем чтение и сохранение для калькулятора по анонимному ключу
create policy "Allow all operations for anon"
  on history
  for all
  using (true)
  with check (true);
```

4. Нажмите зелёную кнопку **«Run»** (или сочетание `Ctrl + Enter` / `Cmd + Enter`).
5. Внизу появится зелёная надпись: `Success. No rows returned`. Таблица готова!

---

### 📌 Шаг 3. Копирование ключей подключения
1. В самом низу левого меню Supabase нажмите на значок шестерёнки **«Project Settings»** (Настройки проекта).
2. В открывшемся меню перейдите в подраздел **«API»** (Data API).
3. Скопируйте два параметра:
   * **Project URL**: выглядит как `https://abcdefghijklmnopqrst.supabase.co`
   * **Project API keys** -> строка **`anon` `public`**: длинный ключ, начинающийся на `eyJhbGciOi...`

---

### 📌 Шаг 4. Вставка ключей в калькулятор GlassLoft
1. Откройте калькулятор: **[https://buchnevserj-del.github.io/calc/](https://buchnevserj-del.github.io/calc/)**
2. Откройте окно **«История расчётов»** (введя PIN `0120`).
3. В верхней плашке облака нажмите **«⚙️ Настройки»**.
4. Переключитесь на вкладку **«⚡ Supabase»**.
5. Вставьте:
   * В поле **Supabase Project URL** — скопированный `https://...supabase.co`
   * В поле **Supabase anon public API Key** — скопированный ключ `eyJhbGci...`
6. Нажмите кнопку **«🧪 Тест связи»** — система проверит подключение и покажет зелёную плашку:
   `✅ Успешное подключение! В облачной базе найдено расчётов: 0`
7. Нажмите **«💾 Сохранить»**.
