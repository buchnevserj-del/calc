# Настройка синхронизации с Яндекс Облаком для GlassLoft

Калькулятор **GlassLoft** теперь оснащён модулем **2-сторонней синхронизации в реальном времени** с **Яндекс Облаком (Yandex Cloud)**.

Все сметы, созданные на любом смартфоне или компьютере, автоматически объединяются в единую защищённую базу данных компании.

---

## Архитектура работы:
1. **Калькулятор на телефоне / ПК** отправляет новые и изменённые сметы через защищённый HTTP-запрос в бессерверную функцию Яндекс Облака (`Yandex Cloud Functions`).
2. **Яндекс Cloud Function** сохраняет сметы в файл `data/history.json` внутри вашего S3-бакета **Yandex Object Storage**.
3. **Любое другое устройство** при открытии калькулятора или сохранении расчёта автоматически скачивает обновления и выполняет слияние баз по времени изменения (`updatedAt`), предотвращая потерю данных.
4. Если замер проводится **оффлайн** (в подвале или без связи), смета сохраняется локально, а при появлении интернета сразу улетает в Яндекс Облако.

---

## Пошаговая инструкция по настройке за 3 минуты:

### Шаг 1: Создание бакета в Яндекс Облаке
1. Войдите в консоль Яндекс Облака: **[console.cloud.yandex.ru](https://console.cloud.yandex.ru/)** под корпоративным аккаунтом.
2. В левом меню выберите **Object Storage** -> **Создать бакет**.
3. Введите название: `glassloft-calc-storage`
4. Доступ к чтению/записи: **Ограниченный** (доступ только по ключам).
5. Нажмите **Создать бакет**.

### Шаг 2: Создание бессерверной функции Cloud Function
1. В левом меню выберите **Cloud Functions** -> **Создать функцию**.
2. Имя функции: `glassloft-sync`
3. Вкладка **Редактор**:
   * Среда выполнения: **Python 3.11**
   * Точка входа: `index.handler`
   * Вставьте код из готового файла **`yandex_cloud_function.py`** в редактор.
   * В файл `requirements.txt` добавьте: `boto3`
4. Вкладка **Параметры**:
   * Включите переключатель **«Публичная функция»** (чтобы калькулятор мог обращаться к ней по HTTPS).
   * В разделе **Переменные окружения** добавьте:
     * `BUCKET_NAME`: `glassloft-calc-storage`
     * `AWS_ACCESS_KEY_ID`: *(Ключ сервисного аккаунта с ролью storage.editor)*
     * `AWS_SECRET_ACCESS_KEY`: *(Секретный ключ сервисного аккаунта)*
     * `API_KEY`: `glassloft2026secret` *(любой ваш секретный ключ)*
5. Нажмите **Сохранить изменения**.
6. Скопируйте ссылку на функцию в блоке «Ссылка для вызова»:
   `https://functions.yandexcloud.net/d4e...`

### Шаг 3: Подключение в калькуляторе GlassLoft
1. В калькуляторе GlassLoft откройте **«История расчётов»** (введя PIN `0120`).
2. В строке статуса Яндекс Облака нажмите кнопку **«⚙️ Настройки»**.
3. Вставьте скопированный URL функции в поле **«URL функции / шлюза Яндекс Облака»**.
4. В поле **«Секретный API-ключ»** укажите ваш ключ (если задавали `API_KEY`).
5. Нажмите кнопку **«🧪 Тест связи»** — система подтвердит подключение зелёным индикатором.
6. Нажмите **«💾 Сохранить»**.

---

Готово! Теперь в окне истории горит зелёный статус **`🟢 Яндекс Облако: Синхронизировано`**, и все сметы компании находятся в едином общем доступе.
