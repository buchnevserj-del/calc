# Бесплатная синхронизация GlassLoft (Firebase / Supabase)

Калькулятор **GlassLoft** поддерживает **100% бесплатную синхронизацию в реальном времени** через сервисы **Google Firebase** или **Supabase**.

Оба сервиса предоставляют постоянный бесплатный тариф (**Free Forever / Spark Plan**), которого с избытком хватает для коммерческих расчётов компании без привязки банковской карты.

---

## Вариант 1 (Рекомендуемый): Google Firebase (Настройка за 2 минуты)

### 1. Создание проекта в Firebase:
1. Откройте **[console.firebase.google.com](https://console.firebase.google.com/)** и войдите под вашим Google-аккаунтом.
2. Нажмите **«Создать проект»** (назовите его, например, `glassloft-calc`). Google Analytics можно отключить.
3. В левом меню перейдите в раздел **«Realtime Database»** (или «База данных в реальном времени») и нажмите **«Создать базу данных»**.
4. Выберите регион (по умолчанию: Бельгия `europe-west1` или США `us-central1`).
5. Выберите **«Режим тестирования»** (или задайте правила доступа: `".read": true, ".write": true`).
6. Вверху скопируйте ссылку на базу данных. Она выглядит так:
   `https://glassloft-calc-default-rtdb.europe-west1.firebasedatabase.app`

### 2. Подключение в калькуляторе:
1. Откройте калькулятор GlassLoft, зайдите в **«История расчётов»** (PIN: `0120`) -> **«⚙️ Настройки Облака»**.
2. Выберите вкладку **Firebase**.
3. Вставьте скопированную ссылку на базу.
4. Нажмите **«🧪 Тест связи»** -> появится зелёная отметка успешного подключения.
5. Нажмите **«💾 Сохранить»**.

*Готово! Теперь при сохранении любой сметы на телефоне она мгновенно появляется на компьютере и всех других устройствах!*

## Вариант 2: Supabase (PostgreSQL + REST API)

### 1. Создание проекта в Supabase:
1. Откройте **[supabase.com](https://supabase.com/)** и зарегистрируйтесь через GitHub или почту.
2. Нажмите **«New Project»** (имя: `glassloft`, придумайте пароль базы).
3. Перейдите в **SQL Editor** и выполните один запрос для создания таблицы:
```sql
create table history (
  id text primary key,
  data jsonb not null,
  timestamp bigint,
  updated_at bigint default (extract(epoch from now()) * 1000)
);

-- Включить публичный доступ для калькулятора
alter table history enable row level security;
create policy "Allow all operations for anon" on history for all using (true) with check (true);
```
4. В разделе **Project Settings** -> **API** скопируйте:
   * **Project URL**: `https://xxxxxxxx.supabase.co`
   * **anon public key**: `eyJhbGciOi...`

### 2. Подключение в калькуляторе:
1. В настройках облака калькулятора выберите вкладку **Supabase**.
2. Вставьте **Project URL** и **anon key**.
3. Нажмите **«🧪 Тест связи»** и **«💾 Сохранить»**.

---

## Преимущества бесплатного облака:
* **0 рублей в месяц** — лимит Firebase (до 50 000 операций в день) и Supabase (до 500 МБ) абсолютно бесплатен навсегда.
* **Работа без интернета** — если на объекте нет связи, сметы сохраняются в телефоне и автоматически выгружаются в облако при выходе на связь.
* **Мгновенное слияние** — сметы не перезаписываются и не теряются, объединяясь по дате и времени.
